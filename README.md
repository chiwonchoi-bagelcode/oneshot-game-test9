# 공동명의 급류타기

세 집주인, 노는 하나. 서로 자기 집이라 우기는 세 사람에게 노를 던져 주며,
급류에 떠내려가다 부서지고 잘려 나가는 **공동명의 집**을 강 끝 기슭까지 몰고 가는
휴대폰 세로 화면용 3D 급류 액션 게임입니다. (툰 셰이딩, 하이앵글 3인칭 추적 카메라)

## 실행

빌드된 파일(`dist/game.js`)이 저장소에 포함되어 있어 바로 실행할 수 있습니다.

- **그냥 열기**: `index.html`을 브라우저로 엽니다. (file:// 에서도 동작)
- **로컬 서버** (휴대폰으로 같은 와이파이에서 접속할 때 권장):
  ```bash
  npx http-server -p 8080 .     # 또는 python3 -m http.server 8080
  ```
  휴대폰에서 `http://<PC IP>:8080` 으로 접속 → 세로 화면으로 플레이.
- 데스크톱에서는 세로 9:16 화면으로 가운데에 표시되며 **마우스 클릭 하나로** 플레이할 수 있습니다.
  (보조 키: `A`/`←` 좌봉식, `S`/`↓` 한가운, `D`/`→` 우말순, `Esc` 일시정지)

## 조작과 규칙

- **집주인을 탭**하면 노가 갑판을 가로질러 휙 날아갑니다. 받은 사람은 곧장 물을 크게 퍼 저어
  집 전체가 그쪽으로 묵직하게 기울며 휘청입니다. 오래 기다린 사람일수록 더 세게 퍼 젓습니다.
- 받은 사람은 **자기 쪽으로만** 젓습니다.
  - **좌봉식**: 왼쪽 기슭만 · **우말순**: 오른쪽 기슭만 · **한가운**: 한가운데만 (가운데에선 집을 바로잡음)
  - 한 사람이 오래 쥐고 있으면 팔이 지쳐 점점 약하게 젓습니다.
- 바위 바로 앞에서 노를 던져 아슬아슬하게 비껴가면 **아슬아슬!** 슬로모션이 터집니다.
- 노를 오래 못 받은 사람은 표정과 몸짓으로 삐칩니다: 팔짱 → 머리에서 김 → 톱을 꺼내 만지작 →
  자기 방 둘레를 쓱싹쓱싹 → **똑!** 침대와 화분을 태운 채 손을 흔들며 떠내려갑니다.
  톱질 중이라도 노를 던져 주면 달랠 수 있습니다(톱질 자국은 남습니다).
- 방이 떨어져 나갈수록 집은 작고 가벼워져 날렵하게 돌지만, 한 번 스쳐도 크게 부서집니다.
- 바위에 부딪히면 벽이 기우뚱하다 쿵 쓰러지고, 가구가 튀어 오르고, 의자와 냄비가 갑판을 미끄러집니다.
- 집이 완전히 부서지면 노를 쥔 사람만 **문짝 한 장**을 타고 버팁니다. 바위에 두 번 더 맞으면 침몰(실패).

## 코스

출발 나루 → 첫 여울 → 바위 정원 → 소용돌이 굽이 → 좁은 협곡 → 둘째 여울 → 소용돌이 굽이 → 마지막 급류 → 기슭

- **소용돌이**: 들어가면 집이 한 바퀴 돌고 튕겨 나갑니다. 일부러 타면 바위 벽 너머로 단숨에 방향을 바꿀 수 있고,
  도는 중에 노를 던지면 그 순간 그 방향으로 빠져나옵니다.
- **좁은 협곡**: 온전한 집(폭 8m)은 양쪽 벽에 긁히며 억지로 비집고 지나갑니다.
  한쪽 방을 떠나보내 날씬해진 집이나, 옆으로 돌아간 집은 깔끔하게 빠져나갑니다.

## 도착 장면 (5가지)

| 장면 | 조건 |
| --- | --- |
| 온전한 공동명의 | 셋 다 태우고, 집이 비교적 온전할 때 |
| 너덜너덜 공동명의 | 셋 다 태웠지만 집이 많이 부서졌을 때 |
| 둘이서 반반 | 한 명이 방을 썰어 먼저 떠났을 때 |
| 이제 진짜 내 집 | 두 명이 떠나고 한 명만 남았을 때 |
| 문짝 한 장 | 집이 산산조각 나고 문짝 하나로 도착했을 때 |

떠나보낸 방들은 결말에서 먼저 기슭에 도착해 손을 흔들고 있고, 떠나던 순간은 폴라로이드 사진으로 남습니다.
발견한 도착 장면은 브라우저에 저장됩니다.

## 개발

```bash
npm install
npm run dev      # esbuild watch + http://localhost:8080
npm run build    # dist/game.js 갱신
npm run simtest  # 헤드리스 봇이 코스를 내려가며 난이도 확인
```

- `src/sim/` — 렌더링과 분리된 순수 시뮬레이션 (강 코스·물살 장, 뗏목 물리, 노/삐침/톱/결말 규칙)
- `src/view/` — three.js 툰 렌더링 (물살 셰이더, 집 모델과 파손 연출, 캐릭터 애니메이션, 파티클, 카메라)
- `src/audio/` — WebAudio 합성 사운드 (물소리·삐걱임·톱질·목소리·음악, 외부 파일 없음)
- `src/ui/` — HUD, 말풍선, 의성어, 결과 화면
- `tools/shots.mjs` — 헤드리스 Chromium으로 시나리오를 돌려 스크린샷을 찍는 시각 점검 도구
